# NeuroNudge

A study planner for keeping track of classes, assignment deadlines, and flashcards.

**Live site:** https://neuronudge-psi.vercel.app/

## Features
- Add classes and track assignment deadlines for each one
- Dashboard with a live countdown to your next deadline
- Flashcard decks with spaced repetition, so cards you struggle with come back sooner
- Focus timer (25 min work, 5 min break) and a daily study streak
- Dark mode and keyboard shortcuts for studying

## Built with
HTML, CSS, and JavaScript. Data is saved locally in the browser.
